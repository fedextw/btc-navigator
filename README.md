# BTC Navigator｜持續學習的合約研究網站

**[下載一鍵啟動 ZIP](https://github.com/fedextw/btc-navigator/raw/refs/heads/codex/btc-navigator-delivery/releases/BTC-Navigator.zip)** · [第一次使用與 Telegram 設定](使用指南.md) · [下載與啟動說明](releases/README.md)

繁體中文 Binance USDT 永續合約研究終端。包含技術指標、SMC／ICT 簡化結構、公開新聞、市場資金脈絡、機器學習、歷史回測、未來紙上驗證及背景收集。**這是研究軟體，不是已證實能獲利的自動交易產品。**

## 一鍵啟動

1. 安裝 **Python 3.11 或更新版本**（建議 3.11）；Windows 安裝時勾選 **Add Python to PATH**。
2. 將整個 ZIP 解壓縮到可寫入的資料夾，不能直接從 ZIP 內執行。
3. Windows 雙擊 **`START.bat`**（`啟動.bat` 也可以）；macOS 雙擊 `啟動.command`；Linux 執行 `bash 啟動.sh`。請勿直接雙擊 `launch.py`，也不要只從 ZIP 拖出單一啟動檔。
4. 首次會連網下載固定版本套件，之後自動開啟瀏覽器並啟動背景研究。若瀏覽器未自動開啟，依終端顯示的本機地址開啟。

macOS 若沒有執行權限，在終端執行 `chmod +x 啟動.command`，再雙擊。首次需可連線 PyPI，不需要 Docker、Node.js 或交易所金鑰。**沒有內附 Python 或獨立 EXE**；Windows／macOS 啟動檔未經原生平台實機驗證，Linux 已測試。

新版啟動器會在離開前保留視窗，並將 Python 版本、套件安裝與啟動輸出寫入 `startup.log`。失敗時請看實際錯誤，不需要猜測閃退原因；資料夾無法寫入時，紀錄改存系統暫存目錄 `btc-navigator-startup.log`。Windows 會優先選擇已安裝的 Python 3.11。

保留啟動視窗，關閉瀏覽器後背景程序仍可執行。按 **Ctrl+C** 結束網站與背景程序。電腦關機、休眠、網路中斷或雲端機器停止時不能持續監控；本包不會安裝作業系統服務或自動開機程序。

### 沒有即時連線時先試用

在資料夾內執行 `python launch.py --demo`（macOS／Linux 用 `python3`）。所有合成行情與紙上紀錄都會標示為示範，並與真實資料分開。範例 CSV 檔名也明確標示為合成資料。

### 全市場背景監控

目前版本預設掃描 Binance `exchangeInfo` 裡全部 **TRADING／PERPETUAL／USDT 計價及保證金**合約，每 5 分鐘更新名單，沒有前 6／100 幣限制，也支援數字前綴、單字元及中文代號。USDC、幣本位與到期交割合約不在此範圍。週期預設 **1h**，可在「全市場訊號 → 監控設定」改成 15m／4h。單幣研究的選擇不限制背景掃描；可從全市場表格直接開啟任一幣種。

每輪預設 60 秒，使用小量並發、已收盤 K 線快取、交易所速率額度及 429／418 暫停；耗時過長或額度不足會顯示延後數量。這不是逐筆成交級的即時服務。預設最低 24h 成交額 500 萬 USDT：低於門檻仍列入掃描，但不訓練／推播，可在設定設為 0 取消篩選。

## 持續學習如何運作

- 背景程序每 **60 秒** 收集公開行情與快照，RSS 最快每 **5 分鐘**、全球背景每 **15 分鐘** 收集一次。
- 首次依候選規則強度排隊，預設每輪最多準備 **3 個幣種模型**，不會瞬間訓練所有幣種；可調為 1～10。每幣先取得最多 **1,500 根**歷史，保留最近 6 根於整個訓練／驗證視窗之外。歷史不足者不會虛構模型。
- 訓練資料與版本持續存入 SQLite／本機檔案；後續可用累積最近最多 **5,000 根**。距現行模型訓練至少 **24 小時**、訓練終點後至少有 **24 根新收盤 K 線**、且上次嘗試至少隔 24 小時才再準備候選。4h 會比 1h 等更久，不是每分鐘重訓。
- 每版保存資料指紋、參數、測試交易與評估，可對照後續紙上結果。模型版本和資料保存在 `.local-state`；不會自行改寫原始碼。
- 模型預測只用歷史 OHLCV。新聞、情緒、費率、OI、穩定幣／TVL 是即時研究背景，**尚未累積成可用來訓練的時間對齊歷史特徵**，因此不把現在的資料填回過去。
- 「持續學習」代表重新擬合與持續評估，**不代表每次重訓都會變得更準，也不保證勝率或收益**。反覆觀看／調整同一測試集會造成過度擬合；真正重要的是之後未曾看過的市場與紙上結果。

回測是固定持有期的 **1× 名目研究策略**，與總覽中的 ATR 研究價位不同。未模擬資金費結算、強平、真實撮合、跳空與極端流動性；不能當成槓桿合約實盤績效。

## 生成式 AI 新聞／市場解讀（選用）

預設 Ollama 本機摘要不需 API 金鑰；安裝後到全市場設定選模型。只有主動切換 OpenAI 才使用付費服務。若需要 OpenAI，可在側欄「AI 摘要設定」輸入自己的 OpenAI API Key，只保存於當次連線記憶體；或在作業系統安全設定 `AI_API_KEY`。不要把金鑰傳到聊天、寫進原始碼或打包分享。

單幣研究可手動點「產生本次 AI 研究摘要」。要背景自動解讀，請在全市場設定保存金鑰，勾選「啟用付費 AI 自動解讀」，並設定每日上限（預設 5 次，台北日界）。合格訊號出現後才呼叫，不會對數百幣種每分鐘呼叫付費 API。Telegram 主訊號先送，文字模型不會阻塞主推播；補充解讀會顯示在網站，主訊號已送達且未過期時也會追加推播。

OpenAI 模式預設模型 `gpt-4.1-mini`，可用 `AI_MODEL` 環境變數更換。**可能產生 API 費用。** 摘要只解讀提供的指標、公開新聞標題與市場背景，不能聲稱讀過全文，也不會更改原始價位或替你下單。未設定金鑰時不會假裝已呼叫 AI。本機數值學習模型與模擬流程不需 OpenAI 金鑰。

## CSV 格式

必備標題：`time,open,high,low,close,volume`。time 使用 UTC ISO 時間或毫秒 Unix；800～5,000 根、2 MB 以內、時間連續、OHLC 合理。左側週期需和資料一致。缺少的收盤時間依週期計算，不會補造價格。匯入資料只做離線研究，來源未經系統獨立驗證，不會取得即時訊號資格。

## 驗證與故障排除

`python launch.py --check` 安裝並檢查環境。安裝後可用 `.launcher-venv/bin/python -m unittest discover -s tests -v`；Windows 路徑為 `.launcher-venv\Scripts\python.exe`。

背景狀態見全市場頁與 `.local-state/scanner.log`；診斷為 `startup.log`。`signals.sqlite3` 保存掃描、訊號、推播與 AI 紀錄，`research.sqlite3` 保存新聞、背景與訓練資料；模型／版本為 `models/`，資料集為 `datasets/`，模擬紀錄為 `paper/`。請備份整個 `.local-state`；金鑰也保存在此，Windows 使用同一登入帳戶的 DPAPI 加密，其他平台為權限 600 的本機檔案，不要上傳分享。換帳戶需重填金鑰。一次只開一個全市場啟動器；連接埠衝突可用 `--port 8502`，仍不可重複監控相同狀態目錄。

本次驗證詳見 `驗證報告.md`。0.2 已實際讀取三個新聞 RSS 與四類全球背景來源；Binance 對此雲端所在地回應 HTTP 451，不能在這裡做真實全市場績效驗證。下載後會使用你電腦的網路讀取來源；遇到限制請檢查合法可用的服務地區與網路設定，不要關閉 TLS 驗證。Telegram 真正手機送達與付費 AI 需你自己的設定後驗證，不能用模擬請求冒充已完成。
